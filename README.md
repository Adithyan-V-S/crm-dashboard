I have completed the assessment for the Full Stack Developer Trainee position. The project is a fully functional CRM Dashboard built with Next.js, TypeScript, and MongoDB.

Features Implemented
Dashboard Layout: Side navigation, top search bar, and main content area.
Company Details: A rich display of company information including dynamic tabs.
Dynamic Tab Switching: The main content area updates automatically when switching between Activities, Contacts, Sales, and other tabs.
Leads Management: Fetching leads from MongoDB with server-side pagination.
Adding new leads via a modal form with advanced validation.
Delete Logic: Multi-select leads using checkboxes and delete them instantly.
Status badges (Open, Sold, Lost, Stalled) with custom colors.
Responsive Design: Clean and professional UI that adapts to screen sizes.

Technical Stack
Frontend: Next.js 15 (App Router), TypeScript, Vanilla CSS (for custom design flexibility).
Backend: Next.js API Routes.
Database: MongoDB with Mongoose ODM.
Icons: Lucide React.
